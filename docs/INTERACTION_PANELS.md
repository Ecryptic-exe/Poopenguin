# Discord 入口與 Embed 路徑

更新：2026-10-29。Account 與 Song 依最新要求精簡；Poopenguin 保留既有互動。

## 入口

| 入口 | 功能 |
|---|---|
| `/menu` | 主資料、Song、Poopenguin、計算工具主選單 |
| `/help` | 指令說明及使用手冊，可返回主選單 |
| `/account` | NET／Chunirec／Chunilib 帳號狀態、連結、同步及個人紀錄 |
| `/chart [query]` | 開啟同一套歌曲卡，初始為視譜；不帶 query 時開搜尋選單 |
| `/score [query]` | 開啟同一套歌曲卡，初始為分數；不帶 query 時開搜尋選單 |
| `/tools` | Rating、定數、容錯、餡蜜計算 |
| `/compare` | 原 A 的最近成績訊息比較，保留 user／kamaitachi 參數 |
| `/permissions` | 原管理者伺服器權限設定 |

Poopenguin 的 `/ask`、`/pick`、`/rng`、`/rcg`、`/gacha`、`/copypasta`、`/keyword` 與子指令保留。實際斜線根入口數量依啟用的模組而定，並保留訊息選單 **View your score**。選配管理、訊息、投票、公告與 AI 模組保留既有啟用條件。

## Account

來源選單固定三類：**CHUNITHM-NET、Chunirec、Chunilib 匯出檔**。選 Chunirec 後另選 jp2／jp，既有兩區帳號和資料均保留；Kamaitachi 不再出現在這個選單，原比較及相容處理器仍可使用既有資料。

| 路徑 | 操作 |
|---|---|
| NET | 未連結顯示登入；已連結顯示同步 |
| Chunirec → jp2／jp | 未連結顯示連結；已連結顯示同步 |
| Chunilib | 顯示 [Chunilib 首頁](https://chuni.tsaibee.org/) 連結；按「匯入檔案」在私人表單傳送自己的 player-data JSON |
| 個人紀錄選單 | Best 50、來源成績；NET 額外提供最近遊玩 |
| 帳號設定 | 分享設定；依目前來源與狀態提供登出 NET、查看 NET 憑證、解除來源、刪除全部本機資料 |

登入、Token、匯入及刪除確認使用私人回應。完成後，仍停留 Account 類別的公開父頁只刷新安全狀態；憑證不寫進公開卡。未對應曲庫的匯入成績仍能由「來源成績」查詢，不假造歌曲對應。

## Song／Chart

歌曲卡保留「返回主選單」與「關閉」按鈕；容錯頁另有自訂 JUSTICE 按鈕，其餘集中在 **選擇單曲功能** 選單：

| 選項 | 顯示內容／後續操作 |
|---|---|
| 視譜 | `/chart` 初始頁，顯示所選難度的 sdvx.in 視譜；缺資料時如實提示 |
| 分數 | `/score` 初始頁，顯示本人的該譜面成績；可選 NET、Chunirec jp2／jp、Chunilib |
| 評價／社群評價 | Poopenguin 既有譜面表資料、來源與匿名玩家統計；下方選單可新增／管理自己的評價及切換有資料的玩家群組 |
| 譜面詳情 | 原本概覽：曲名、曲師、難度、定數與版本資訊 |
| 成績分佈 | 依可信 Chunirec ID 按需取得公開資料，以 C 完整視圖產圖；24 小時快取、樣本／日期／來源與限制；切難度保留本頁 |
| 容錯／失分 | 各目標分數的 JUSTICE／ATTACK／MISS 容錯及每個判定的失分 |
| 別名 | 目前歌曲的全域／本伺服器別名；選單新增、移除、返回單曲；擁有者另可重新載入 |
| 找錯歌／重新搜尋 | 保留原查詢，排除目前歌曲家族重新比對；候選選單可重新輸入 |

難度選單保留一般／WORLD’S END 類型、星數、收錄版本與下架狀態。多頁資料才增加頁次選單。評價的「新增／管理」及群組選擇共用一個次選單，保留關閉所需空間。

排行榜、曲繪分頁、相關連結、Rating 表、鏡像、歌曲比較及篩選／標籤入口已從本套歌曲 UI 移除。原處理器保留相容用途，不另把它們塞回主選單。通用計算仍在 `/tools`；原 `/compare`、`!compare` 與訊息選單維持原 A 流程。

同曲同曲師的一般／WE 版本合併為一個搜尋候選，實際 Song／Chart ID 各自保留。真正同名異曲師或別名衝突仍需選擇，候選有版本與狀態標註。`gengaozo` 可在同卡切換一般 STAR、WE 狂☆☆☆☆☆／STAR、敷☆☆／AMAZON、覚☆☆☆／PARADISE，三個 WE 依曲庫標為下架。

成功選歌後，可另收到私人別名建議；確認才加入目前伺服器共用別名，衝突不覆寫既有對應。私人提醒、評價管理與背景表單不會覆蓋公開歌曲卡。評價自動帶入已有本人資料，背景補充可選；一筆即可顯示匿名統計，評論與身分不公開。

## 訊息更新與關閉

一般介面公開，由開啟者操作，切頁與結果更新同一則訊息。超過約 0.6 秒的操作會先顯示「處理中…」，完成後在原訊息換成結果。歌曲頁錯誤可重新選取原功能，搜尋可重新輸入。

每個 Embed 有開啟者專用關閉；關閉只收起訊息，不刪資料。主面板關閉會取消登入等待、釋放讀取資源並阻止晚到結果重開；關閉私人提醒不影響父歌曲卡。各種來源的分享設定與他人成績權限仍沿用原檢查。

Poopenguin 非 CHUNITHM 功能集中在 `chuni_penguin/cogs/poopenguin/`；舊 `legacy_b` 路徑保留相容。完整功能、選配條件見 [Poopenguin 清單](POOPENGUIN_FEATURES.md)。逐層元件見 [介面清單](EMBED_UX_PROPOSAL.md)，評價資料政策見 [玩家評價](CHART_REVIEWS.md)。
