# 成績分佈

更新：2026-10-19。先前版本只有十二張 MASTER 離線樣本，不能提供一般選歌後的統計；本輪已補上按需取得資料的流程。

## 使用方式

1. 用 `/chart` 或 `/score` 找到歌曲。
2. 從功能選單選「成績分佈」，再選要看的難度。
3. 首次取得公開資料與產圖時，原訊息顯示「處理中…」；完成後在同一張卡顯示圖、樣本數、擷取日期及來源。
4. 同譜面的有效資料與圖片會快取 24 小時。再次查詢使用快取，不重複抓取；切換難度會查該難度，保持在成績分佈頁。

## 圖片內容

- 沿用 C 專案的完整視圖與數值模型，沒有更改其公式。
- 橫軸為來源的 BEST 枠平均分組，縱軸為譜面分數。
- 黑線是來源公布的群體平均；有「估」的線是 C 模型推估，不是單一玩家的實測能力。
- 使用完整視圖，避免原本的高分裁切把實測線整條藏掉。
- 來源定數與本機曲庫不同時會註明；不混用兩份資料。

## 資料與缺資料情況

來源為 Chunirec 公開曲目頁。以本機曲庫的可信 Chunirec ID 直接取得，驗證歌曲、難度及來源編號；不靠同名搜尋猜測對應，不需要玩家 Token。

沒有可信對應、WORLD’S END、來源沒有可用資料、樣本不足或定數不在 C 模型範圍時，顯示原因與可採取的操作。來源暫時失敗且有舊的已審核樣本時，才使用標明日期的離線備用資料；不把舊資料標成剛更新。

同譜面同時查詢會共用處理，最多八個待處理項目；來源請求與產圖有逾時及停止機制，失敗會短暫等待後再試。只處理使用者所選譜面，不在背景抓完整曲庫。
