# Account／Song 實際介面清單

更新：2026-10-19。以下為目前實作，取代先前「常用按鈕＋更多選單」方案。

## 共通規則

- 公開主頁由開啟者操作，在同一則訊息更新；敏感資料與自己的評價另開私人訊息。
- 慢操作在原訊息顯示「處理中…」，結果回到原處。快速操作不閃提示。
- 每頁保留「關閉」。關閉訊息不刪資料，私人頁關閉不影響公開父頁。
- Song 公開介面只保留關閉按鈕；搜尋、功能、分頁、別名等操作使用選單。

## Song 各層

| 層級 | Embed 內容 | 按鈕 | 選單／動態選項 |
|---|---|---|---|
| S0 搜尋入口 | `/chart` 提示搜尋開視譜；`/score` 提示搜尋開分數 | 關閉 | 搜尋歌曲／簡寫；有前張卡才列返回單曲 |
| S1 候選確認 | 查詢、候選數；同曲家族版本摘要 | 關閉 | 歌曲候選（曲師、版本、狀態）；重新輸入曲名／簡寫 |
| S2 單曲卡 | 下表所選功能的內容；頁尾只留版本、功能與頁次 | 關閉 | 固定八項功能；難度／特殊譜面；有多頁才列頁次；分數才列來源；評價才列管理／統計群組 |
| S3 別名 | 目前歌曲與可見別名，標全域／本伺服器 | 關閉 | 新增別名、移除別名、返回單曲；擁有者另列重新載入 |
| S4 私人別名建議 | 成功確認歌曲後，提示是否把本次簡寫加入伺服器共用別名 | 加入別名、關閉 | 只有需再次選歌時才使用候選 |
| S5 私人評價管理 | 目前評價、帶入的本人 Rating 與已存背景；缺資料標未提供 | 填寫／修改評價、選用背景補充、有舊評價才列刪除、關閉 | 後續使用 Discord 表單 |
| S6 私人評價表單 | 喜好、體感難度、遊玩次數、目標、文字評論 | Discord 提交／取消 | 各欄原選項；與真正 chart_id 綁定，修改時預填 |
| S7 選用背景表單 | Rating 區間、主力等級、經驗、擅長／不擅長 | Discord 提交／取消 | 原背景選項；不必先填才能評價 |

### S2 固定八項功能

| 選項 | 內容 | 額外選單 |
|---|---|---|
| 視譜 | 所選難度的視譜；缺資料如實提示 | 難度／特殊譜面 |
| 分數 | 本人該難度成績 | NET、Chunirec jp2／jp、Chunilib；難度／特殊譜面 |
| 評價／社群評價 | 原 Poopenguin 表的心得、標籤、SSS 星數與來源；玩家匿名統計 | 同一選單列「新增／管理我的評價」及有資料的整體／Rating／主力／經驗統計；難度 |
| 譜面詳情 | 原概覽的歌曲、曲師、難度、定數、一般／WE 與收錄資訊 | 難度／特殊譜面 |
| 成績分佈 | 按需取得 Chunirec 公開資料，以 C 完整視圖產圖；24 小時快取、樣本與日期、來源及解讀限制 | 難度／特殊譜面；WE 如實提示無來源統計，不跳回概覽 |
| 容錯／失分 | 目標分數容錯及單個判定失分 | 難度／特殊譜面 |
| 別名 | 進入 S3，保留目前歌曲脈絡 | S3 選單 |
| 找錯歌／重新搜尋 | 排除目前歌或同歌家族，重新比對原字串 | S1 候選或重新搜尋 |

八項功能保持固定順序。缺視譜、統計、物量或成績時，顯示明確缺資料提示，不編造內容；缺視譜等不適用分頁可回到譜面詳情並提示。成績分佈切換難度維持原功能，依該難度重新取得資料；沒有資料時直接在本頁說明。

同一張卡的單曲選單、難度、額外評價／來源、必要頁次最多使用四列選單，第五列可放關閉，符合 Discord 限制。寫評價與切換統計群組共用一列，避免多頁資料時擠掉關閉。

移除的 Song 選項：排行榜、獨立曲繪、相關連結、Rating 表、鏡像、歌曲比較、篩選與標籤入口。通用計算在 `/tools`；原 `/compare` 保留原 A 最近訊息方式。內部舊處理器仍供相容使用。

## 狀態、匿名及資料保留

返回單曲會保留實際版本、難度、功能、來源與頁次。來源切換不混入其他玩家資料；別名確認重新檢查同名衝突，不改掉舊對應。正常搜尋不要求玩家解讀資料庫 ID；一般／WE、版本及下架標註保留。

評價自動讀已有本人資料，背景補充可選。匿名統計暫時一筆就顯示；公開只含整體與單一維度分組數值，不含身分與文字評論。本人可修改／刪除，提交保存當時的背景快照，舊視窗不能覆蓋新版。

Poopenguin 保留原指令與面板，非 CHUNITHM 功能集中至 `cogs/poopenguin`，不在本輪重設其 Embed。詳細清單與選配條件見 [Poopenguin 功能](POOPENGUIN_FEATURES.md)。
